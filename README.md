# MAS-2026

An agent-based model (Mesa) of golden shiner schools. Each fish follows three local rules: repulsion, orientation and attraction. The goal is to add light-dependent swimming speed, the mechanism by which fish groups find dark areas.

- **Install:** Python 3.11, then `python -m pip install -r checks/requirements.txt`.
- **The model:** [shiner_model.py](shiner_model.py).
- **Checks, trials, results and decisions:** [checks/README.md](checks/README.md). Start there.
- **The complete notebook:** [Golden_Shiner_MAS_Complete.ipynb](Golden_Shiner_MAS_Complete.ipynb).
- **Earlier prototypes:** [past_repo/](past_repo/README.md).
